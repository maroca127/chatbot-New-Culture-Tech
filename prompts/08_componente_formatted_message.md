* **Camada:** Camada 4 — Interface & Formatação de Respostas

## 🎯 Objetivo
Criar um componente React que renderiza o texto retornado pela IA interpretando formatações ricas em Markdown (títulos, negritos, itálicos, quebras de linha e tópicos) de maneira segura.

```text
Crie um componente React chamado "FormattedMessage.jsx" utilizando a biblioteca "marked" para converter respostas da IA com formatação Markdown (negrito, listas, links e quebras de linha) em HTML seguro.
```
