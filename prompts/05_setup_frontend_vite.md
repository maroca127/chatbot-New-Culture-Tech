# 💬 Prompt 05: Inicialização do Frontend React com Vite

* **Projeto:** 01 — Chatbot de Suporte Full-Stack (AfesuTech)
* **Camada:** Camada 4 — Interface & Frontend
* **Diretório Alvo:** `frontend/`

---

## 🎯 Objetivo
Inicializar o projeto frontend utilizando o bundler **Vite** com **React (JavaScript)** e instalar as dependências de ícones (`lucide-react`) e parser de Markdown (`marked`).

---

## 📋 Comandos do Terminal para as Alunas

Execute no terminal dentro da pasta raiz do projeto:

```bash
# 1. Cria o projeto React com Vite na pasta frontend
npm create vite@latest frontend -- --template react

# 2. Entra na pasta do frontend
cd frontend

# 3. Instala as dependências base
npm install

# 4. Instala a biblioteca de ícones e o formatador de Markdown
npm install lucide-react marked
```
